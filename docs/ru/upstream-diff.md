Отличия от апстрима
===================

pbFenom — форк [fenom/fenom](https://github.com/fenom-template/fenom) **3.1.0**.
Синтаксис шаблонов не менялся: изменены поведение движка, устойчивость и скорость.
Каждая строка ниже проверена исполнением кода — на всё есть регрессионный тест.

## Безопасность

Первые четыре строки относятся к режиму, когда шаблоны редактирует не полностью
доверенный пользователь. В MODX это обычная ситуация: правка чанков доступна не только
администратору.

| Что | Апстрим 3.1.0 | pbFenom |
|---|---|---|
| `{$.php.f()}` при `DENY_PHP_CALLS` | выполняется — опция не проверяется | блокируется |
| `{$.php.f()}` при `DENY_NATIVE_FUNCS` | выполняется, хотя `{f()}` запрещён | подчиняется тому же белому списку |
| `disable_accessor` | объявлена, но нигде не проверяется | работает |
| два фильтра вызовов | соединяются через И — не проходит ничего | любой подходящий разрешает |
| автоэкранирование | `ENT_COMPAT` — `'` не экранируется | `ENT_QUOTES\|ENT_SUBSTITUTE\|ENT_HTML5` |
| битый UTF-8 в значении | значение молча становится пустым | подставляется символ замены |
| `escape:'js'` | `</script>` проходит насквозь | hex-экранирование, выйти нельзя |
| `escape:'неизвестно'` | возвращает строку без экранирования | бросает исключение |
| `{strip}` | не сжимает пробелы; переключает экранирование и не возвращает обратно | сжимает; экранирование не трогает |
| проверка корня шаблонов | префикс без разделителя — проходит `<корень>_backup` | с разделителем; нулевой байт отвергается |
| `Provider::clean()` | удаляет файл по симлинку, за пределами каталога | удаляет только саму ссылку |
| каталог компиляции | по умолчанию `/tmp`; подложенный файл исполняется | обязателен; world-writable отвергается; файлы `0640` |
| имя файла кэша | `crc32` — коллизия за ~65 тыс. имён | префикс `sha256` |
| цикл `{include}` / `{insert}` | неперехватываемый фатал: стек или память | исключение с именем шаблона, мгновенно |
| разогнавшийся `{macro}` | стековый лимит PHP, без имени макроса | лимит `MAX_MACRO_RECURSIVE` |
| `eval()` | используется в трёх режимах | отсутствует полностью |

## Корректность

| Что | Апстрим 3.1.0 | pbFenom |
|---|---|---|
| `AUTO_RELOAD` после правки шаблона | падает, пока кэш не вычистишь руками | перекомпилирует |
| два движка, один каталог кэша | отдают артефакты друг друга | ключ включает состав модификаторов и тегов |
| тег `{for}` | фатал: методы удалены в 3.0.0, регистрация осталась | восстановлен |
| `{use}` + `{paste}` | пишет невалидный PHP в кэш | работает |
| `{foreach ... last=}` над генератором | фатал на `count()` | работает |
| `{$.block}` | Undefined constant — имена без кавычек | работает |
| `{$.tag}` | фатал: метод никогда не существовал | удалён |
| `{"😀"\|length}` | 3 | 1 |
| `strip` + не-UTF-8 шаблон | весь вывод молча пустой | текст сохраняется |
| `addFunctionSmart()` с замыканием | TypeError — принимает только строки | любой callable |
| `addFunction()` | колбэк получает `($params, $tpl, $var)` | сигнатура колбэка и есть API шаблона |
| `getModifier('x')` с одним аргументом | TypeError на собственном значении по умолчанию | работает |

## Производительность

Замеры на PHP 8.3, одинаковые шаблоны, тёплый кэш. Сгенерированный код побайтово
совпадает с апстримом — ускорение получено не за счёт изменения вывода.

| Сценарий | Апстрим | pbFenom | Разница |
|---|---:|---:|---:|
| компиляция шаблона 256 КБ | 183 мс | 103 мс | ×1.8 |
| компиляция шаблона 512 КБ | 4 771 мс | 170 мс | ×28 |
| компиляция шаблона 1 МБ | 35 844 мс | 340 мс | ×106 |
| `{include}` ×1000 в цикле | 385 мкс | 235 мкс | ×1.6 |
| страница при `AUTO_RELOAD` | 25.3 мкс | 7.6 мкс | ×3.3 |
| `{foreach}`, таблица 1000 строк | 454 мкс | 422 мкс | −7% |
| размер артефакта | 45% занимают комментарии | за опцией | −45% |

Компиляция была квадратичной по числу блочных тегов: каждое закрытие `{/foreach}`,
`{/block}` или `{/macro}` копировало всё накопленное тело шаблона. Отсюда 35 секунд на
мегабайте — и линейное время после исправления.

## Совместимость

**Не изменилось:** синтаксис шаблонов целиком, смысл и названия опций, модификаторы,
теги, аксессоры, лицензия BSD-3-Clause.

**Требует правок при переходе:**

* пространство имён `pbFenom` вместо `Fenom`;
* `factory()` требует каталог компиляции — дефолта `/tmp` больше нет;
* `ENT_QUOTES` меняет вывод: `'` становится `&apos;`;
* `addFunction()` по умолчанию читает сигнатуру колбэка;
* формат кэша изменён — каталог нужно очистить один раз.

**Досталось от апстрима 3.0.0**, а не от форка: `ProviderInterface` типизирован (свои
провайдеры нужно привести к сигнатурам), требуется PHP 8.2+, удалён `registerAutoload()`.

## Почему переименовано пространство имён

В MODX каждый компонент грузит свой `vendor/` в один процесс, а классы в PHP глобальны.
Без переименования чужая копия Fenom могла бы выиграть гонку автозагрузки и подменить
пропатченный движок непропатченным — молча, без ошибки. Composer этому помешать не может:
он не знает о `vendor/` соседнего компонента.
