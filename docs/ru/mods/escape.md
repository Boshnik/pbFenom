Модификатор escape
==================

Экранирует строку для безопасной вставки в вывод. Стратегия зависит от того, куда
именно вы вставляете значение; по умолчанию — HTML.

```smarty
{$text|escape}
{$text|escape:'html'}
{$text|escape:$type:$charset}
```

`e` — псевдоним `escape`.

## Стратегии

| Стратегия | Для чего | Реализация |
| --------- | -------- | ---------- |
| `html` (по умолчанию) | текст HTML и атрибуты **в кавычках** | `htmlspecialchars()` с `ENT_QUOTES\|ENT_SUBSTITUTE\|ENT_HTML5` |
| `attr` | то же самое; понятнее читается у атрибута | как выше |
| `js` | литерал JavaScript внутри `<script>` | `json_encode()` с флагами `JSON_HEX_*` |
| `url` | сегмент пути URI | `rawurlencode()` — пробел станет `%20` |
| `query` | значение в query-строке | `urlencode()` — пробел станет `+` |

Неизвестная стратегия **бросает** `InvalidArgumentException`, а не возвращает строку
без экранирования — молчаливый возврат означал бы полное отсутствие защиты.

`$charset` действует только для `html` / `attr`, по умолчанию — `pbFenom::$charset`.

## Замечания

Одинарная кавычка экранируется, поэтому атрибут в одинарных кавычках безопасен:

```smarty
<a href='{$url|escape}'>          {* &apos; не разорвёт атрибут *}
```

Битый UTF-8 заменяется, а не отбрасывается: без `ENT_SUBSTITUTE` `htmlspecialchars()`
возвращает пустую строку, и значение молча исчезает.

`js` возвращает **готовый литерал вместе с кавычками**, свои добавлять не нужно:

```smarty
<script>var a = {$text|escape:'js'};</script>    {* правильно *}
<script>var a = "{$text|escape:'js'}";</script>  {* неправильно: кавычки задвоятся *}
```

Именно флаги `JSON_HEX_*` не дают `</script>` закрыть окружающий тег.

Экранирование **не учитывает контекст**: модификатор не знает, куда попадёт результат,
а `auto_escape` везде применяет стратегию `html`. В частности, оно **не делает URL
безопасным** — `javascript:` в `href` пройдёт нетронутым, проверяйте схему сами.

При включённом `auto_escape` явный `{$x|escape}` экранирует дважды. Для уже
экранированного значения используйте `{raw $x}`.
